# 💳 DS Banking

**DS Banking** is a modern mobile banking application built with **React Native**, powered by a **PHP & MySQL backend**. It provides a secure, fast, and user-friendly way to manage finances directly from your phone.

---

## 🚀 Features

* 📊 **Account Management** – View your balance in real time
* 💸 **Money Transfers** – Send money securely to other users
* 🧾 **Transaction History** – Track all your transactions easily
* 📱 **Phone Top-Ups** – Buy mobile credit from supported providers
* 🤖 **NOVA Chatbot** – Get instant assistance with very fast responses
* 🧮 **Credit Calculator** – Calculate your credit with a low-interest formula by DS Banking
* 💳 **Apple Pay Integration** – Add your card to Apple Pay for quick and secure payments
* 👤 **Profile Management** – View and manage your personal and contact details
* 🎨 **Modern UI/UX** – Clean design with smooth and intuitive user experience

---

## ⚙️ How It Works

When a user registers:

* A unique **16-digit account number** is generated
* A **16-digit card number** is created
* A **3-year expiry date** is assigned
* A **3-digit CVV** is generated

For security:

* Transfers require valid and correct user details
* Fake or invalid users cannot manipulate the system

---

## 🏗️ Tech Stack

* **Frontend:** React Native
* **Backend:** PHP
* **Database:** MySQL

---

## 🔐 Security

DS Banking is built with a strong focus on security:

* Validated transactions between real users
* Protection against fake or manipulated accounts
* Secure handling of financial and personal data

---

## 📌 Notes

* Supports phone top-ups from two providers
* Designed for scalability and performance
* Fast chatbot response system (NOVA)
* Focused on simplicity, security, and clean design
